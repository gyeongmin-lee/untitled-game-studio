# Hamstar Game Studio

> 작은 햄스터들의 거대한 꿈. 갓겜을 만들고, 시장을 개척하고, 전설의 개발사가 되세요.

**Game Dev Story × Slay the Spire × Reigns**

카이로소프트의 경영 시뮬레이션이 가진 중독성에, 덱빌딩의 전략적 깊이와 Reigns의 분기 선택을 결합한 스튜디오 운영 게임. 햄스터들이 키보드를 둥가둥가 두드리며 인생작을 만든다.

## 무엇을 만드는가

플레이어는 신생 게임 스튜디오의 디렉터가 되어, 직접 이름 붙인 게임을 한 작품씩 세상에 내보낸다. 어떤 게임을 만들지, 누구를 뽑을지, 언제 출시할지 — 모든 결정이 스튜디오의 운명을 만든다. 차고에서 시작한 햄스터 두 마리가 업계의 전설로 자리잡는 여정.

## 핵심 컨셉

- **내가 만든 게임이라는 몰입감** — 모든 게임 제목은 직접 타이핑한다. 자동 생성은 없다.
- **갓겜의 레시피를 발견하는 재미** — 카드 조합이 게임의 정체성을 만든다. 서사형 RPG, 소울라이크, 코지 심... 처음 시도하는 조합은 장르 개척자로 기록된다.
- **실제 게임 개발의 메타포** — 보스를 때리는 게 아니라, 메타크리틱·스팀 평가·매출·스트리머 픽업 같은 진짜 KPI로 판정된다.
- **체감되는 스튜디오 성장** — 차고에서 시작한 2인 팀이 명문 개발사가 되는 여정. 첫 게임과 마지막 게임은 완전히 다른 작품이어야 한다.
- **귀여움이 무기다** — 햄스터, 해달, 카피바라... 작은 동물들이 만드는 거대한 게임. 갭 모에 그 자체가 어그로다.

## 핵심 루프

```
스튜디오 운영
  ↓ 채용 · 연구 · 사무실 확장 · 평판 관리
프로젝트 그린라이트
  ↓ 제목 입력 · 규모 선택 · 덱빌딩
개발
  ↓ 카드 설치로 게임을 완성 · 분기 이벤트로 결정의 무게
출시 운영
  ↓ KPI 대시보드 관리 · 패치 · 마케팅 · 위기 대응
정산
  ↓ 망작에서 신드롬까지 — 등급에 따라 IP·명성·자금 변동
        ↓
   다시 스튜디오 운영으로
```

매 사이클마다 스튜디오는 조금씩 달라지고, 카드 라이브러리는 두꺼워지고, 새로운 전략이 열린다.

## 지향점

- 한 판이 끝나면 다른 전략으로 다시 하고 싶은 게임
- 5분이면 들어가고 한 시간이면 빠져나오기 힘든 게임
- 내 스튜디오의 역사가 진짜 내 이야기처럼 느껴지는 게임
- 스크린샷 한 장만 봐도 클릭하고 싶은 게임
